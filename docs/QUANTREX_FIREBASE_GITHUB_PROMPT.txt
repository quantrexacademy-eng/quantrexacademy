3. FIREBASE STORAGE — PERFECT IMAGE LOADING
-----------------------------------------------------------------------------

Bucket: the project default (quantrexacademy-app.appspot.com / .firebasestorage.app).

3.1 Canonical figure URLs
Student HTML must use Quantrex Storage URLs, not cdn-question-pool.getmarks.app / cdn-assets.getmarks.app.

Pipeline (already in QxOwnedFigs / QxImgClean / proxy-image):
1. Prefer owned Storage object (questions/figs/..., figures/, images/).
2. Else /api/proxy-image?clean=1&url=... (Function, same origin, cacheable).
3. Else /api/restore-image for known broken figs.
4. Never leave a raw Marks CDN src in the painted DOM for question/option/solution images.

3.2 Storage layout
  questions/figs/**     question + option + solution figures (public read)
  figures/**            extra diagrams
  images/**             UI / covers
  rfc/** or notes/**    flash cards / revision note images
  profiles/{uid}/**     avatars (user write, public read, 5MB, image/*)
  pdfs/** books/**      signed-in read
  teacher_pdfs/{uid}/** teacher upload
  teacher_videos/{uid}/**

3.3 Rules (keep production, never allow write: if true)
- Public read only for question figures and UI images.
- Writes: admin console / Cloud Functions / owner paths with size + contentType checks.
- Flash-card and formula-card images must remain readable (do not hide .qx-rfc-img / .fc-img).
- CORS: Storage download URLs must work from www.quantrexacademy.com and the TWA WebView.

3.4 Image render rules in the SPA
- loading="eager" for the current question stem/options; lazy only for off-screen thumbs.
- decoding="async"
- max-width 100% on solution images (assets/qx-sol-vis.css)
- onerror: QxOwnedFigs.retryOnError — one Storage retry, then proxy, then hide broken icon (never dump HTML)
- Do not wrapBareLatex on stored JSON (it split subscripts). Recover at render only.
- Revision notes: keep data-URI and Storage src; never replace with "[image content will be provided separately]".
- Hide .katex-error { display:none } AND keep throwOnError:true so parse failures do not dump red HTML.

3.5 Performance
- WebP where already stored; do not recompress official exam figures if it destroys labels.
- CDN is Firebase Hosting + Storage (Google). Do not add a third CDN.
- Prefetch next-question images only (1 ahead), not the whole chapter.
