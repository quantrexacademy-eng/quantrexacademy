YOU MUST DO NOW (GoDaddy DNS — only you can log in)
---------------------------------------------------

A) Point domain to VERCEL (recommended for quantrexacademy.com)

  1. Open: https://dcc.godaddy.com/control/portfolio
  2. Click: quantrexacademy.com → DNS / Manage DNS
  3. Remove parking / website builder A and CNAME for @ and www
  4. Add:

     Type    Name    Value                    TTL
     ----    ----    -----------------------  ---
     A       @       76.76.21.21               600
     CNAME   www     cname.vercel-dns.com      600

  5. Save. Wait 10–60 minutes.

  6. Vercel Domains panel (confirm SSL):
     https://vercel.com/ajay-kumar-saroj-s-projects/quantrexacademy/settings/domains

     Add if not listed:
       quantrexacademy.com
       www.quantrexacademy.com

B) Firebase Auth — allow your domain (required for Email/Google login)

  1. Open:
     https://console.firebase.google.com/project/quantrexacademy-live/authentication/settings

  2. Authorized domains → Add:
       quantrexacademy.com
       www.quantrexacademy.com
       quantrexacademy-lemon.vercel.app

  3. Sign-in method → Enable:
       Email/Password  ON
       Google          ON (optional)
